Forecasts with a track record

The method is chosen by tested accuracy, and the error is shown

Tessera tries six methods, including seasonal Holt-Winters, on your most recent history and keeps the one that would have been most accurate. Each forecast states its method and how far off it was.

Free, on your machine

Install in two minutes

With Python 3.11 or newer

git clone https://github.com/vvipinthomas/tessera.git
cd tessera && pip install -e .
tessera serve
# open http://127.0.0.1:8710

The console prints a one-time setup code. Enter it in the browser to create the first admin, optionally with the sample retail workspace.

On Cloudflare

cd tessera/cloudflare && npm ci
npx wrangler r2 bucket create tessera-data
npx wrangler secret put TESSERA_MASTER_KEY   # and the R2 keys
npx wrangler deploy

Runs in Cloudflare Containers behind a Worker, with every change backed up to R2. A restart or upgrade restores itself.

With Docker

docker compose up -d --build
docker compose logs tessera | grep "Setup code"
# open http://localhost:8710

Data lives in one folder: the metadata database, the DuckDB warehouse, uploads, exports and the encryption key. Back it up like any other folder.

Encrypted secrets

Connection passwords, tokens and model keys are sealed with AES-256-GCM and never returned by the API.

Hardened sign-in

scrypt password hashing, HttpOnly SameSite cookies, CSRF checks, lockout after five failures, OIDC with PKCE.

Locked-down engine

Parser-checked read-only SQL, no file or network access from queries, query timeouts and row limits.
